# PowerBi-Dashboard
An interactive Power BI dashboard developed to analyze sales performance, key KPIs, and business trends. The dashboard uses calculated measures, filters, and interactive visualizations to explore sales performance across different areas.

Key Features

Sales performance and KPI tracking

Trend analysis

Interactive filters and slicers

Calculated measures using DAX

Interactive charts and visualizations

Dashboard designed for clear and easy data analysis

Tools Used

Power BI, DAX, Data Visualization
